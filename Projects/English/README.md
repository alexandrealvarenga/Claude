# Inglês B1 → C2

Plano de estudo de inglês baseado em Natural Method e Comprehensible Input: 30 minutos ativos por dia, um tema por semana, ciclo 1 com 12 semanas.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `index.html` | Roteiro interativo: semanas, atividades diárias, vocabulário, checklist e progresso |
| `Projecto.md` | Contexto completo do projeto. Cole numa conversa com o Claude para retomar o plano |

## Como usar

- **Pelo Claude (recomendado):** https://claude.ai/artifact/5ZQYj2QAfJgzdnHwqwEDBb
  O progresso fica salvo na conta do Claude e aparece em qualquer computador.
- **Pelo arquivo `index.html`:** abra no navegador ou publique com GitHub Pages.
  Nesse caso o progresso fica salvo **só no navegador** em que você marcar os dias, e não é sincronizado com a versão do Claude.

## Atualizações

Quando o plano mudar (novo ciclo, novos horários), substitua os dois arquivos e faça um novo commit.
