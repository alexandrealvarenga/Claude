# oracle-analytics-cloud Claude Skill

This folder contains a Claude Code skill for Oracle Analytics Cloud, Oracle Cloud Infrastructure, Oracle Fusion Analytics Warehouse/Analytics Cloud, and Oracle Autonomous Data Warehouse.

## Installation

Copy this folder to your Claude skills directory, for example:

```bash
mkdir -p ~/.claude/skills
cp -R oracle-analytics-cloud ~/.claude/skills/
```

Then use Claude Code normally and mention tasks involving OAC, OCI, FAW/FAC, or ADW.

Example:

```text
Use the oracle-analytics-cloud skill to create a DR plan for OAC and ADW.
```

## Files

- `SKILL.md`: main skill instructions
- `references/checklists.md`: operational checklists
- `examples/prompts.md`: useful prompt examples
